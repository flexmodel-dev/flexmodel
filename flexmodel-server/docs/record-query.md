# 表单高级查询

Apps 记录列表工具栏的筛选按钮打开气泡框，支持增加、删除最多 10
个条件，选择全部满足或任一满足。操作符和值输入随字段类型变化；应用后回到第一页并清除勾选，取消或点击外部不修改已应用条件。列表展示已启用的条件数量，可重新编辑或清空。查询仅作用于当前列表，切换表单或应用后重置，不写入共享页签配置。

`GET /api/apps/{appId}/forms/{formName}/records` 的可选 `filter` 参数是 URL 编码后的 JSON 字符串，例如：

```json
{
  "_or": [
    {
      "amount": {
        "_gte": 100
      }
    },
    {
      "approved": {
        "_eq": false
      }
    }
  ]
}
```

根节点只能是 `_and` 或 `_or`，包含 1–10 个单字段、单操作符条件，不支持嵌套。空参数表示无高级查询。后端复用页签筛选校验，拒绝未知或内置字段、无效操作符、类型不匹配、空值和超过
16000 字符的条件；引用字段按记录 ID 查询。

- 数字、日期、日期时间、时间：等于、不等于、大于、大于等于、小于、小于等于。
- 布尔、选项、分类、多选、引用：等于、不等于。
- 其他文本类字段：等于、不等于、包含、不包含、开头是、结尾是。

高级查询组与关键词、视图页签、主子表关联约束以 AND 合并，分页总数和排序基于同一查询。Excel 导出 `forms[]` 中的 `filter`
字符串沿用相同契约，在 `scope=FILTERED` 时生效；前端按当前筛选导出时自动携带它。
